# 🛡️ SOC-Shield

### Log Analyzer & Threat Detection System

**SOC-Shield** is a lightweight, Python-based cybersecurity tool designed to analyze web server access logs, identify suspicious activities, detect common web attack patterns, and generate structured security incident reports.

It combines **signature-based threat detection**, **IP blacklist matching**, and **brute-force monitoring** to help identify potential security threats within server logs.

The project is developed using Python 3 and its built-in libraries, keeping it simple, lightweight, and easy to extend.

---

## ✨ Features

### 🔍 1. Security Log Analysis

- Parses web server access log files (`.log`).
- Extracts and analyzes relevant request information.
- Identifies suspicious requests and security events.
- Supports offline analysis of existing log files.

### 🚨 2. Web Attack Detection

Detects suspicious request patterns associated with common web vulnerabilities:

| Attack Type                | Description                                                                  |
| -------------------------- | ---------------------------------------------------------------------------- |
| SQL Injection (SQLi)       | Identifies suspicious SQL-related patterns in requests.                      |
| Cross-Site Scripting (XSS) | Detects potential script injection patterns.                                 |
| Path Traversal             | Identifies suspicious attempts to access files outside intended directories. |
| Command Injection          | Detects patterns associated with operating system command injection.         |
| Sensitive File Probing     | Identifies requests targeting potentially sensitive files and resources.     |

Detection is based on configured keywords and patterns. Results indicate suspicious activity, not necessarily a confirmed successful attack.

### 🌐 3. Honeypot IP Detection

- Reads known suspicious IP addresses from `blackIPs.txt`.
- Compares client IP addresses extracted from logs against the blacklist.
- Flags matching IP addresses for further investigation.
- Supports updating the blacklist with additional threat intelligence data.

### 🔐 4. Brute-Force Login Monitoring

- Monitors HTTP `401 Unauthorized` responses.
- Tracks repeated authentication failures.
- Helps identify potential brute-force login activity.
- Highlights suspicious authentication patterns for investigation.

### ⚠️ 5. Threat Severity Classification

Security events are categorized into four severity levels:

| Severity    | Meaning                                                            |
| ----------- | ------------------------------------------------------------------ |
| 🔴 CRITICAL | Potentially severe security threat requiring urgent investigation. |
| 🟠 HIGH     | Significant suspicious activity requiring attention.               |
| 🟡 WARNING  | Potential security concern worth reviewing.                        |
| 🔵 INFO     | Informational security event or observation.                       |

### 📊 6. CSV Security Reports

- Exports detected security incidents to `incidents_report.csv`.
- Provides a structured format for reviewing detected events.
- Enables further analysis using spreadsheet tools or Python.
- Helps maintain records of suspicious activity.

### ⚙️ 7. Configurable Detection

- Uses `config.json` for system configuration.
- Supports configurable threat-detection keywords and patterns.
- Separates configuration data from the main application logic.
- Provides a foundation for extending the detection system.

## ⚙️ Installation & Usage

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/YOUR_USERNAME/SOC-Shield.git
```

Replace `YOUR_USERNAME` with the actual GitHub username.

### Step 2: Navigate to the Project Directory

```bash
cd SOC-Shield
```

### Step 3: Verify Python Installation

```bash
python3 --version
```

Ensure Python 3 is installed.

On Debian-based Linux distributions, such as Ubuntu or Kali Linux, Python 3 can be installed using:

```bash
sudo apt update
sudo apt install python3
```

### Step 4: Configure the Project

Before running the application:

1. Ensure `config.json` contains the required configuration settings and detection keywords.
2. Ensure `blackIPs.txt` contains the IP addresses to monitor.
3. Ensure `dummy.log`, or the log file selected in the project configuration, is available.
4. Verify that all file paths match the application configuration.

**Security Note:** Never commit passwords, API keys, confidential log data, or other sensitive information to a public repository. Use sanitized sample configuration and log files when publishing the project.

### Step 5: Run SOC-Shield

From the project's root directory, execute:

```bash
python3 main.py
```

The application processes the configured log data, checks for suspicious activity, and performs the implemented detection routines.

### Step 6: Review the Security Report

After successful execution, inspect the generated report:

```text
incidents_report.csv
```

The report contains security findings generated during analysis.

You can open the CSV file in a spreadsheet application or process it using Python for further investigation.

## 🔒 Security Considerations

SOC-Shield is designed to assist with security monitoring and log investigation.

Important limitations:

- Signature-based detection may produce false positives.
- Unknown attack patterns may not be detected.
- An HTTP `401` response alone does not confirm a brute-force attack.
- A blacklisted IP match is an indicator for investigation, not definitive proof of malicious activity.
- Detected patterns do not necessarily indicate successful exploitation.
- This tool does not replace a production Security Information and Event Management (SIEM) platform.
- SOC-Shield analyzes logs; it should not be treated as an automatic attack prevention system.

**SOC-Shield should be used only with logs and systems that you own or are authorized to analyze.**

## ✨ Features

### **🔍 Dynamic Log Parsing:**

Safely parses line-by-line web access logs (\`.log\`) into clean data points.

Detects malicious payloads in requested URLs (SQL Injection, XSS, Path Traversal, Command Injection, and Sensitive File Probing).

Compares incoming client IPs against known malicious IP feeds (\`blackIPs.txt\`).

### 🔐 Brute Force Tracking:

Tracks repeated \`401 Unauthorized\` responses per IP using in-memory tracking dictionary.

### 📊 Severity Matrix Classification:

Categorizes threats into **CRITICAL**, **HIGH**, **WARNING**, and **INFO** levels.

### 📁 Custom Configuration Support:

Easily update attack patterns, thresholds, and status codes via \`config.json\`.

### 📑 CSV Incident Reporting:

Export all flag-matched incidents directly to \`incidents\_report.csv\` for security analysts.
